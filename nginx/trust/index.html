Set up this device for Vyaptek HMS

HMS on this server uses a secure connection (HTTPS) on the hospital network. Each computer, phone or tablet needs to trust this HMS server once. It takes a minute and needs no administrator.

Open HMS  Already set up? This opens HMS securely.

Windows computer
  1. Download Trust-Vyaptek-HMS.bat.
  2. Open the downloaded file. If the browser asks, choose Keep. If Windows says it protected your PC, click More info, then Run anyway.
  3. Windows asks whether to install a certificate from Vyaptek HMS … LAN CA. Click Yes.
  4. Close every browser window, then open HMS again.

This trusts the server for the Windows user who ran it. Chrome, Edge and Firefox all use it.

Android phone or tablet
  1. Download the certificate.
  2. Open Settings and search for CA certificate (usually under Security → More security settings → Encryption & credentials → Install a certificate).
  3. Choose CA certificate, then Install anyway, and pick vyaptek-hms-ca.crt from Downloads. The phone may ask for its PIN.
  4. Close Chrome and open HMS again.
iPhone or iPad
  1. In Safari, download the profile and tap Allow.
  2. Open Settings, tap Profile Downloaded near the top, then Install (it shows “Not Verified”; that is expected).
  3. Then Settings → General → About → Certificate Trust Settings, and switch on Vyaptek HMS … LAN CA.
  4. Open HMS again in Safari.
Mac
  1. Download the certificate and open it; Keychain Access adds it to the login keychain.
  2. In Keychain Access, double-click Vyaptek HMS … LAN CA, open Trust, and set When using this certificate to Always Trust.
  3. Close the browser and open HMS again.
Firefox still shows a warning
  1. Download the certificate.
  2. In Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, pick the file, and tick Trust this CA to identify websites.
For the hospital's IT team

The certificate authority belongs to this HMS server alone. It is limited (X.509 name constraints) to this server's own names and to private network addresses, so it cannot vouch for any other website. Its private key never leaves the server.

With Active Directory, trust it on every PC at once instead: add vyaptek-hms-ca.crt to a Group Policy Object under Computer Configuration → Policies → Windows Settings → Security Settings → Public Key Policies → Trusted Root Certification Authorities, linked to the hospital's computers.

To reach HMS by another DNS name, add it to nginx\conf\server-names-extra.conf in the HMS folder. Within the hour the server makes a new certificate authority that covers it, and every device must trust the new one from this page.
